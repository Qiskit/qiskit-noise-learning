# Changelog fragments

Pending changelog entries live here as files named `<PR-number>.<type>.md`, where `<type>` is one
of `added`, `changed`, `fixed`, `deprecated`, `removed`, or `security`. Each file's contents are the
changelog entry itself. [Towncrier](https://towncrier.readthedocs.io/) collects these into
`CHANGELOG.md` at release time.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for details.
