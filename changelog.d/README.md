# Changelog fragments

Pending changelog entries live here as files named `<PR-number>.<type>.md`. Each file's contents are
the changelog entry itself. [Towncrier](https://towncrier.readthedocs.io/) collects these into
`CHANGELOG.md` at release time.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the valid `<type>` values and the full workflow.
