Qiskit Noise Learning
=====================

A Python toolkit for randomization-based quantum noise characterization, built
on top of Qiskit.

.. note::

   **Alpha software.** This library is unversioned and under active development.
   Interfaces are unstable and may change without notice between commits.

The library has two levels of interface. The low-level interface exposes objects
representing core concepts in noise learning, enabling custom design of every
aspect of a noise learning protocol. The higher-level interface wraps a stock
workflow into an easy-to-use :class:`~qiskit_noise_learning.noise_learner.NoiseLearner`.
